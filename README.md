# Taco

Shared packing lists for a two-person household. Replaces Google Keep.

## Run locally

```bash
npm install
npm run dev
```

Then open the Local URL in your browser. On your phone (same Wi-Fi), use the Network URL Vite prints.

## Add to Home Screen (iPhone)

1. On your iPhone, open the Network URL in **Safari** (not Chrome).
2. Tap the **Share** button.
3. Scroll and tap **Add to Home Screen**.
4. Confirm the name **Taco** and tap **Add**.

Taco opens full-screen (no Safari chrome) in standalone mode. Safe areas keep content clear of the notch and home indicator.
